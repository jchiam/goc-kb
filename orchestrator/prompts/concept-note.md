# Concept note format reference

This file documents the expected format for concept pages in the vault.
It is not loaded by the orchestrator — it is included here as a reference for prompt tuning.

Concept notes are generated by the meeting-note.md system prompt as part of each meeting processing run.

---

## Format

```markdown
---
tags:
  - concept
---

# Title

One-paragraph description of this concept based on available context.

## Mentioned In
- [[YYYY-MM-DD-meeting-slug]]
- [[YYYY-MM-DD-other-meeting]]
```

## Naming conventions

| Type | Slug | Title |
|---|---|---|
| Project | `project-name` | Project Name |
| Person | `firstname-lastname` | First Last |
| System/tool | `system-name` | System Name |
| Strategic theme | `theme-name` | Theme Name |

## When concept notes are created

A concept note is created the **first time** a topic appears in the vault. On subsequent meetings, the orchestrator skips writing concept notes for slugs that already have a file in `wiki/concepts/`. The `Mentioned In` section is not retroactively updated — use Obsidian's backlink panel to trace all references.
